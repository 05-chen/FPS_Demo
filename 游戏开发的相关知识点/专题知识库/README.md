## 使用方式

1. 先看自己当前问题对应的专题
2. 再根据“现象 → 模块 → 根因 → 验证”框架定位
3. 对照模板工具做最小验证
4. 把每次修复的经验写回知识库

## 一句话总结

你真正需要的，不是背知识点，而是建立一套“会定位、会判断、会验证、会修复”的工程能力。
